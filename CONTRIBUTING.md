# Editing the RF Lab wiki

The public site mounts `content/` at `/rf-lab/`. The legacy `wiki_files/`
archive is not published.

- Put each page in `content/<page-slug>/index.md`.
- Use `content/_index.md` only for the `/rf-lab/` landing page.
- Keep small images and lightweight attachments beside the page that uses them.
- Do not add large design files, datasets, or archives to `content/`.
- The responsible PI or project owner should host large downloads in an
  authoritative Dropbox, OneDrive, or equivalent institutional location and
  add that external link to the page.
- Clearly mark a download as pending when no current owner-managed link exists.
- Use root-relative links for other group wikis.
