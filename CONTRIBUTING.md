# Editing the RF Lab wiki

The public site mounts `content/` at `/rf-lab/` and `wiki_files/` at
`/rf-lab/files/`.

- Put each page in `content/<page-slug>/index.md`.
- Use `content/_index.md` only for the `/rf-lab/` landing page.
- Link to downloads with `/rf-lab/files/<filename>`.
- Use root-relative links for other group wikis.
